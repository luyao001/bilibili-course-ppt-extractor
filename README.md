# bilibili-course-ppt-extractor

> Updated implementation and usage: [RELIABILITY.md](RELIABILITY.md).
从 B 站课程/讲座视频中自动提取 PPT 课件页面，按讲次生成 PDF，按章节归档。

适用场景：老师上课录屏但不出课件、网课视频只有录播没有讲义 —— 把视频里的 PPT 自动"还原"成可翻阅的 PDF。

> 本项目源于对一套 98 讲、总时长约 22 小时的大学课程实录的完整实践（全部讲次自动处理 + 程序审查 + 抽样人工视觉验收）。

## 原理

```
视频(B站分P) ──下载──► 视频流(480P)
   │
   ▼  ffmpeg 0.5s/帧 抽取 160x90 分析帧
时间方差掩码 ──► 剔除持续变化区域(讲师人像/压缩噪声)
   │
   ▼  块级翻页切分 (8x4 分块)
"翻页 = PPT 区域整块大幅变化；噪声 = 全画面微小变化"
   │
   ▼  取每稳定段中点原帧 (844x474)
OCR 筛选内容页 ──► 剔除片头校徽页 / 纯讲师独占页 / 深色转场页
   │
   ▼  组内峰值合并 (vanish 指标)
"同页动画递进 = 旧内容只增不减(vanish≈0)；翻页 = 旧内容消失"
   │
   ▼  每组保留信息最全一帧 (Canny 边缘密度最大)
img2pdf 合成 PDF ──► 按 章节/ 讲次 归档
```

### 针对真实录播视频的几个关键处理

| 难点 | 处理方式 |
|---|---|
| 讲师在画面中持续走动，导致帧间差异恒高于阈值、页面被切碎 | 时间方差掩码 + 人脸框定位讲师常驻列带，从切页与合并判定中排除 |
| 低码率视频全局压缩抖动，固定阈值失效 | 块级切页：按"最大变化块"而非全画面均值判定，天然区分噪声与翻页 |
| 老师逐条标注/板书式推演（同一页十几步） | vanish 指标（内容像素消失率）+ 版面相似度，递进序列只保留信息最全一帧 |
| "与门→或门"这类同版式、内容替换的页面被误合并 | 模板区域排除：全程在场的固定像素（标题条/装饰）不参与内容消失判定 |
| 片头 logo、章节转场卡混入 | 顶部纯白检测 + 深色页占比 + OCR 文字丰富度三重筛选 |

## 安装

```bash
# 需要 Python 3.9+；Windows/Linux 均可
pip install -r requirements.txt
```

## 使用

```bash
# 整套视频（全部分P）
python extract.py BV1qFM86PE6c --out "E:\\课件"

# 只处理某几个分P，4 路并行
python extract.py BV1qFM86PE6c --pages 1-10 --workers 4

# 登录态可解锁更高清晰度（导出 cookies.txt 为 Netscape 格式）
python extract.py BV1qFM86PE6c --cookies cookies.txt
```

| 参数 | 说明 |
|---|---|
| `bvid` | 视频BV号 |
| `--pages` | 分P范围：`all` / `4` / `1-10` / `1,3,5` |
| `--out` | PDF 输出目录（按`第N章/`归档） |
| `--work` | 中间文件目录（视频/分析帧/页面PNG，可随时删除） |
| `--workers` | 并行数，>1 时自动按文件锁互斥 |
| `--cookies` | B站 cookies（Netscape 格式），可解锁 720P+ |
| `--force` | 强制重跑已完成的分P（断点续跑默认跳过） |

处理完成后自动输出审查报告（PDF 完整性/空白页/页数密度），异常讲次会明确提示人工复核。

## 实测效果

一套 98 讲 / 22 小时的工科课程实录（讲师出镜合成 + 纯PPT录屏两种版式混合）：

- 全部 98 讲自动完成，产出 1182 页课件 PDF
- 程序审查（PDF 完整性、空白页、页数密度）0 问题
- 抽样人工视觉验收：页面类型与内容合规

## 已知限制

- 未登录 B 站只能取 480P，PPT 大字清晰但小字图表略糊；提供 cookies 可到 720P+
- 讲师入镜的合成版式视频，页面中会保留讲师（源视频如此，无法分离）
- 板书式推演的讲次页数会比"原始PPT"多（每页对应一个讲解步骤），属预期行为
- 动画密集的页面取的是信息最全的定格帧，不含动画过程
